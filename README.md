# Algorithme de répartition

Algorithme de répartition en Python inspiré du Choixpeau magique (Harry Potter).

## Description

Projet réalisé en binôme dans le cadre de ma formation en BUT Informatique. L'objectif était de développer un algorithme de répartition inspiré du fonctionnement du Choixpeau magique de la licence Harry Potter, en s'appuyant sur l'extraction, le nettoyage et la structuration de données à partir de fichiers textes et de fichiers JSON.

## Fonctionnalités

- Extraction de données depuis des fichiers texte et JSON
- Nettoyage et structuration des données
- Algorithme de répartition basé sur des critères définis

## Technologies utilisées

- Python
- JSON

## Lancer le projet

\`\`\`bash
python main.py
